자동 갱신 중지됨

활성 폴더를 5초마다 확인합니다. API 모드에서는 자동 색인에도 전송·비용이 발생합니다. 자동 갱신 중지는 이미 시작한 색인을 취소하지 않습니다.

색인 상태 확인 중…


검색 폴더 설정
기존 폴더를 그대로 등록하세요. 포함/제외는 해당 폴더 기준 하위 경로를 쉼표로 구분합니다. 포함을 비우면 전체 하위 폴더입니다.
PPTX·XLSX·HWPX는 위치를 보존해 읽습니다. 구형 바이너리 HWP는 `--hwp-executable`로 지정한 로컬 변환기가 있어야 `HWP text` 위치로 색인되며, 없으면 파일별 실패 목록에 남습니다. 설정은 현재 DB 옆에 로컬로 저장됩니다.


프로젝트·결정·문서 관계 (로컬 고급 설정)
자동 추정하지 않고, 활성·색인된 문서 경로만 명시적으로 연결합니다. 저장 뒤 프로젝트 또는 결정 이름으로 탐색하세요.
설정 파일에는 프로젝트명·결정명·문서 경로가 들어가며 이 PC에만 저장됩니다. 자동 의미 관계나 coverage 개선을 보장하지 않습니다.


검색: 관련 문단 목록 · 질문: 검색한 근거를 바탕으로 답변 · 결정 이력: 원문에 명시된 변경 문장만 날짜순으로 표시 · 관련 문서 묶음: 문서별 최고 근거 하나씩




답변·근거 검수 기록 (로컬 비공개)
질문 버튼으로 만든 현재 답변을 저장한 뒤, 원문을 확인하고 판정하세요. 두 설정을 비교할 때는 각 답변에 같은 실험 이름을 붙이세요. 이 판정은 사람이 입력한 검토 기록이며 자동 의미 평가가 아닙니다.
검수 기록을 불러오는 중…
질문·답변·표시된 파일 경로/발췌와 메모, 실험 이름이 이 PC에 저장됩니다. 회사 정보가 있을 수 있으므로 원문 그대로 공개하지 마세요.


개인 업무 효율 기록 (로컬 비공개)
대표 과제 10~15개를 줄마다 적으세요. 기존 탐색과 RAG의 순서를 균형 있게 섞습니다. 시작 후 원문 확인을 끝냈을 때 종료하세요. 같은 과제 반복의 학습 효과는 완전히 제거되지 않습니다.
기록을 불러오는 중…
기록은 이 PC에만 저장됩니다. 익명 집계에는 과제·메모·경로·개별 기록이 들어가지 않습니다. 중단·취소된 측정은 성공/소요시간으로 기록하지 않습니다.
