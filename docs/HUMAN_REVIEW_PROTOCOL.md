# 답변·근거 사람 검수 프로토콜

이 문서는 로컬 검수 기록의 `supported` / `partial` / `unsupported` 라벨을 일관되게 남기기 위한 기준이다. 이 프로토콜 자체는 검수 결과나 실제 업무 성과가 아니다.

## 검수 단위

질문 하나의 전체 답변과 번호 인용이 있는 문장을 각각 판정한다. 원문 뷰어에서 해당 인용 문장과 필요한 앞뒤 문맥을 열어 확인한다. 파일 수정 시각, 파일명, 모델의 설명만으로 지지 여부를 추정하지 않는다.

## 라벨 기준

- `supported`: 인용 원문이 문장의 모든 사실과 범위, 조건, 수치를 직접 뒷받침한다.
- `partial`: 핵심 일부는 원문에 있지만 질문의 필요한 항목·기간·조건·비교 대상 중 하나 이상이 빠졌거나 더 넓은 주장을 한다.
- `unsupported`: 인용 원문에 해당 주장이 없거나, 다른 대상/시점/속성의 내용을 근거로 삼았거나, 원문과 모순된다.

`partial`이나 `unsupported`에는 가능한 한 `missing_evidence`, `wrong_subject`, `wrong_time`, `wrong_metric`, `contradiction`, `other` 중 하나를 메모에 적는다. 메모에는 회사 문서 원문이나 고객 식별자를 복사하지 않는다.

## 절차

1. 답변을 생성하고 source 링크로 원문 위치를 연다.
2. 전체 답변을 먼저 판정한다.
3. 인용 번호가 있는 각 문장을 판정한다. 인용 번호가 없어도 전체 답변 판정은 남긴다.
4. 같은 사례를 다른 사람이 검수한다면, 앞선 판정·메모를 보기 전에 독립적으로 판정한다.
5. 두 판정이 다르면 원문 위치를 함께 확인하고 합의하지 못한 경우 `partial`로 남긴다. 원래 두 판정은 덮어쓰지 말고 별도 기록으로 보존한다.

## 공개 가능한 결과

`익명 집계 내려받기`의 count만 공개 후보로 사용한다. 질문, 답변, 파일명/경로, 발췌, 메모, 시각, 검토자 정보가 들어 있는 `*.reviews.sqlite3`는 공개 저장소에 넣지 않는다. 표본 수, 검수자 수, 단일 사용자/AI 작성 fixture 여부, 제외 기준을 함께 적지 못하면 비율을 경력서 성과로 쓰지 않는다.
