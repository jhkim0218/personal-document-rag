# 개인 업무 효율 사례 연구 템플릿

이 문서는 실제 회사 PC에서 사용자가 처리 권한을 가진 문서로만 작성한다. 원문, 파일명, 폴더 경로, 고객·동료 식별 정보는 기록하지 않는다.

## 측정 질문

| ID | 과제 유형 | 기존 방식 | RAG 방식 | 성공 기준 |
| --- | --- | --- | --- | --- |
| W01 | 과거 결정 근거 찾기 | 파일 탐색 + 문서 내 검색 | 자연어 검색 + 원문 열기 | 정확한 원문을 열어 확인 |
| W02 | 정책·정의 확인 | 폴더 탐색 | 질문 + 인용 확인 | 인용이 원문을 지지 |
| W03 | 두 자료 비교 | 수동 메모 | 근거가 붙은 비교 초안 | 두 원문을 모두 검증 |

동일한 성격의 실제 과제를 10~15개까지 추가한다. 기존 방식과 RAG 방식은 가능하면 다른 날에 섞어 수행해 단순한 숙련 효과를 줄인다.
